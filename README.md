# LAR – Layer Adaptive Responder

LAR ist der Symbiose-Partner von KARGA.

KARGA prüft:
- Achse (O, Z, T)
- Nummernbereich (001–243)
- Modultyp (tmp, vec, re)
- Verträglichkeit

LAR verstärkt:
- gute Ergebnisse
- korrigiert schlechte Ergebnisse
- gibt Vorschläge
- optimiert die Platzierung
- erhöht Kompetenz
- senkt Risiko
- verbessert Slide-Modus

LAR arbeitet in 6E:
1. Erkennen
2. Ebene
3. Einordnung
4. Entscheidung
5. Ergebnis
6. Erweiterung

LAR + KARGA = RESPO-Symbiose.
